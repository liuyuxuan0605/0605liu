## bstInsert(value, frames)

- 操作类型: `other`
- 说明: 标准 BST 插入操作
- 详细步骤：
  1. 从根节点开始比较
  2. 新值 < 当前节点值 → 递归插入左子树
  3. 新值 > 当前节点值 → 递归插入右子树
  4. 找到空位置后创建新节点，颜色默认为红色
  5. 记录路径上的比较操作到 frames

## fixInsert(z, frames)

- 操作类型: `other`
- 说明: 插入后的红黑树修复，恢复红黑性质
- 详细步骤：
  1. 新节点 z 为红色
  2. 如果父节点为黑色，无需修复
  3. 如果父节点为红色（冲突），检查叔叔节点颜色：
     - 情况1：叔叔为红色 → 父节点和叔叔变黑，祖父变红，继续向上
     - 情况2：叔叔为黑色，且为 LR 型 → 先左旋父节点，转为 LL 型
     - 情况3：叔叔为黑色，且为 LL 型 → 右旋祖父，父节点变黑，祖父变红
     - 对称情况：RL → 右旋父节点；RR → 左旋祖父
  4. 最后将根节点设为黑色

- 操作类型: `other`
- 说明: 查找操作中的值比较
- 详细步骤：
  1. 比较目标值与当前节点值

  4. 如果大于，递归查找右子树

## 红黑树性质

1. 每个节点非红即黑
2. 根节点为黑
3. 所有叶子（NIL）为黑
4. 红节点的子节点必为黑（无连续红）
5. 任意节点到叶子的路径黑节点数相同（黑高一致）

## 插入修复的三种情况

### 情况1：叔叔为红色

- 处理：父节点和叔叔变黑，祖父变红
- 继续向上检查

### 情况2：叔叔为黑色，LR 型

- 处理：先左旋父节点，转为 LL 型
- 然后按情况3处理

### 情况3：叔叔为黑色，LL 型

- 处理：右旋祖父，父节点变黑，祖父变红
- 修复完成

## 删除修复的四种情况

### 情况1：兄弟为红色

- 处理：兄弟变黑，父节点变红，旋转父节点
- 转换为兄弟为黑色的情况

### 情况2：兄弟为黑色，两子均黑

- 处理：兄弟变红，双黑向上传递
- 继续向上检查

### 情况3：兄弟为黑色，远侄子为红

- 处理：旋转父节点，兄弟继承父节点颜色，父节点和近侄子变黑
- 修复完成

### 情况4：兄弟为黑色，近侄子为红

- 处理：旋转兄弟，兄弟变红，近侄子变黑
- 转换为情况3
