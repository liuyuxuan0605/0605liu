# 12.3 图遍历

在本节中，我们介绍两种用于探索图的算法，从图中的一个顶点 i 开始，
并找到所有可以从 i 到达的顶点。这两种算法最适合用于采用邻接表表示
的图。因此，在分析这些算法时，我们将假设底层表示为邻接表。

## 12.3.1 广度优先搜索

bread-first-search 算法从顶点 i 开始，首先访问 i 的邻居，然后是 i 的邻居
的邻居，再然后是 i 的邻居的邻居的邻居，依此类推。
该算法是对二叉树广度优先遍历算法（第6.1.2节）的推广，且非常相
似；它使用一个队列 q，最初只包含 i。然后它重复地从 q 中提取一个元
素，并将其邻居添加到 q 中，前提是这些邻居以前从未出现在 q 中。图的
广度优先搜索算法与树的广度优先搜索算法的唯一主要区别在于，图的算
法必须确保不会多次将同一个顶点添加到 q 中。它通过使用一个辅助布尔
数组 seen 来跟踪已经被发现的顶点来实现这一点。

。这一处理在内循环中进行，每次迭代花费恒定时间，总共花费 O(m) 时
间。因此，整个算法的运行时间为 O(n + m) 时间。

## 12.3.3 Depth-First Search (1/2)

定理 12.3. When given as input a 图 , g , that is implemented using the 邻接
表 data structure, the bfs(g, r) algorithm runs in O( n + m ) time.
广度优先遍历具有一些非常特殊的性质。调用 bfs(g, r) 最终会将每个从
r 可以到达的顶点 j 入队（并最终出队）。此外，与 r 距离为 0 的顶点（即
r 本身）会先于距离为 1 的顶点进入队列，距离为 1 的顶点会先于距离为
2 的顶点进入队列，依此类推。因此，bfs(g, r) 方法会按与 r 的距离递增的
顺序访问顶点，而无法从 r 到达的顶点则根本不会被访问。
因此，广度优先搜索算法的一个特别有用的应用是计算最短路径。为
了计算从 r 到其他每个顶点的最短路径，我们使用 bfs(g, r) 的一个变体，
该变体使用一个长度为 n 的辅助数组 p。当一个新顶点 j 被加入到 q 时，
我们设置 p[j] = i。通过这种方式，p[j] 成为从 r 到 j 的最短路径上的倒数
第二个节点。重复这个过程，通过取 p[p[j]]、p[p[p[j]]]，依此类推，我们
可以重建从 r 到 j 的最短路径（的反向）。
12.3.2 深度优先搜索
depth-first-search 算法类似于遍历二叉树的标准算法；它首先完全探索一
个子树，然后返回到当前节点，再探索另一个子树。另一种理解深度优先
搜索的方法是，可以说它类似于广度优先搜索，只不过它使用栈而不是队
列。
在执行深度优先搜索算法时，每个顶点 i 都会被分配一个颜色 c[i]：如
果我们从未见过该顶点，则为白色；如果我们正在访问该顶点，则为灰色

单的方法是将其视为递归算法。它从访问顶点 r 开始。访问顶点 i 时，我

表中发现的任何白色顶点。最后，我们完成对 i 的处理，因此将 i 标记为
黑色并返回。
