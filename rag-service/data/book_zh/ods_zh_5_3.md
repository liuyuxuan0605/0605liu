# 5.3 哈希码

上一节讨论的哈希表用于将数据与由 w 位组成的整数键关联。在许多情况
下，我们拥有的键不是整数。它们可能是字符串、对象、数组或其他复合
结构。要对这些类型的数据使用哈希表，我们必须
将这些数据类型映射到 w 位哈希码。哈希码映射应具有以下属性：
1. 如果 x 和 y 相等，那么 x.hashCode() 和 y.hashCode() 也相等。 2. 如果
x 和 y 不相等，那么 x.hashCode() = y.hashCode() 的概率应该很小（接
近 1/2w）。
第一个属性确保，如果我们将 x 存储在哈希表中，随后查找一个等于 x
的值 y，那么我们会找到 x——正如我们所期望的那样。第二个属性将将
我们的对象转换为整数时的损失最小化。它确保不相等的对象通常具有不
同的哈希码，因此很可能存储在哈希表中的不同位置。

（英文术语：HashMap）

## 5.3.1 原始数据类型的哈希码

像 char、byte、int 和 float 这样的小型原始数据类型通常很容易找到哈希

少的位组成。（例如，在 Java 中，byte 是 8 位类型，float 是 32 位类型。
