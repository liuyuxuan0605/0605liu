## 7.1.2 总结

下列定理总结了随机二叉搜索树的性能：
定理 7.1. A random binary search tree can be constructed in O(n log n)
time. In a random binary search tree, the 查找(x) operation takes O(log n)
expected time.
我们应该再次强调，定理7.1中的期望是关于用于创建随机二叉搜索树
的随机排列。特别地，它不依赖于x的随机选择；它对每一个x的取值都成
立。
