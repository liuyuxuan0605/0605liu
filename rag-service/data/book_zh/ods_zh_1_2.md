# 1.2 接口

在讨论数据结构时，理解数据结构的接口与实现之间的区别非常重要。接
口描述了数据结构的功能，而实现描述了数据结构是如何实现这些功能的
。
一个 interface，有时也称为 abstract data type，定义了数据结构所支持
的操作集合以及这些操作的语义或含义。接口并不告诉我们数据结构如何
实现这些操作；它只提供了支持的操作列表，以及每个操作接受的参数类
型和每个操作返回的值的具体说明。
另一方面，数据结构 implementation 包括数据结构的内部表示以及实
现数据结构支持的操作的算法定义。因此，一个接口可以有多种实现。例
如，在第2章中，我们将看到使用数组实现 List 接口的实现方式，而在第3
章中，我们将看到使用基于指针的数据结构实现 List 接口的方式。每种方
式都实现了相同的接口 List，但方法不同。

## 1.2.1 队列、栈和双端队列接口

队列接口表示一个元素集合，我们可以向其中添加元素并移除下一个元素
。更准确地说，队列接口支持的操作有
• add(x)：将值 x 添加到队列中
• remove(): 从队列中移除下一个（之前添加的）值 y，并返回 y
请注意，remove() 操作不需要参数。队列的 queue- ing discipline 决定应移
除哪个元素。有许多可能的排队规则，最常见的包括先进先出（FIFO）、
优先级以及后进先出（LIFO）。

移除元素，就像在杂货店收银台排队结账时队列（或排队）一样。这是最

## 1.2.3 USet 接口：无序集合

USet 接口表示一个无序的唯一元素集合，它模仿数学上的 set。一个 USet
包含 n 个 distinct 元素；没有元素出现超过一次；元素没有特定顺序。US
et 支持以下操作：
1. size(): 返回集合中元素的数量 n
2. add(x)：如果集合中尚未存在元素 x，则将其添加到集合中；在集合
中不存在元素 y 使得 x 等于 y 的情况下，将 x 添加到集合中。如果 x 被
添加到集合中，则返回 true，否则返回 false。
3. remove(x)：从集合中移除 x；在集合中找到一个元素 y，使得 x 等于
y，并移除 y。返回 y，如果没有这样的元素则返回 null。
4. find(x)：在集合中查找 x，如果它存在的话；
在集合中找到一个元素 y，使得 y 等于 x。返回 y，如果不存在这样
的元素则返回 null。
这些定义在区分 x（我们要移除或查找的元素）和 y（我们可能移除或
查找的元素）时有点讲究。这是因为 x 和 y 可能实际上是不同的对象，但
仍然被视为相等。这样的区分是有用的，因为它允许创建将键映射到值的
dictionaries 或 maps。
要创建一个字典/映射，需要构造称为对（Pairs）的复合对象，每个对
包含一个 key 和一个 value。如果两个对的键相等，则它们被视为相等。
如果我们在 USet 中存储某个对 (k, v)，然后稍后使用对 x = (k, null) 调用 fi
