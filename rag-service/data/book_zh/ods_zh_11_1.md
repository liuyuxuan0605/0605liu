# 11.1 基于比较的排序

在本节中，我们介绍三种排序算法：归并排序、快速排序和堆排序。这些
算法中的每一种都接受一个输入数组 a，并将 a 的元素按照非递减顺序排
序，预计时间为 O(n log n) (。这些算法都是 comparison-based。它们的第
二个参数 c 是一个比较器 (Comparator)，实现了 compare(a, b) 方法。这些
算法不关心排序的数据类型；它们对数据执行的唯一操作是使用 compare(
a, b) 方法进行比较。回想一下，在第 1.2.4 节中，compare(a, b) 如果 a < b
则返回负值，如果 a > b 返回正值，如果 a = b 返回零。
