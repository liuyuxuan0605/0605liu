第九章
红黑树
在本章中，我们介绍红黑树，这是一种具有对数高度的二叉搜索树版本。
红黑树是最广泛使用的数据结构之一。它们作为主要的搜索结构出现在许
多库实现中，包括 Java 集合框架以及 C++ 标准模板库的多个实现中。它
们还在 Linux 操作系统内核中使用。红黑树受欢迎有几个原因：
1. 存储 n 个值的红黑树的高度最多为 2 log n。 2. 对红黑树执行 add(x)
和 remove(x) 操作的时间为 O(log n) worst-case。 3. 在 add(x) 或 remove(
x) 操作期间执行的旋转的摊还次数是常数。
这三个性质中的前两个已经使红黑树优于跳表、树堆和替罪羊树。跳表和
树堆依赖于随机化，它们的 O(log n) 运行时间只是预期时间。替罪羊树对
其高度有保证的上限，但 add(x) 和 remove(x) 仅以 O(log n) 的摊还时间运
行。第三个性质只是锦上添花。它告诉我们，添加或删除一个元素 x 所需
的时间，比查找 x 所需的时间微不足道。1
