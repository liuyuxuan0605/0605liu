# 1.6 代码示例

本书中的代码示例是用 Java 编程语言编写的。然而，为了让不熟悉 Java
所有构造和关键字的读者也能理解，本书中的代码示例进行了简化。例如
，读者不会看到任何 public、protected、private 或 static 关键字。读者也不
会看到关于类层次结构的过多讨论。某个特定类实现了哪些接口或继承了
哪个类，如果与讨论相关，应当可以从随附的文本中清楚地看出。
这些约定应该使任何具有 ALGOL 传统中任何语言背景的人都能理解
代码示例，包括 B、C、C++、C#、Objective-C、D、Java、JavaScript 等
。希望了解所有实现的完整细节的读者，建议查看随书附带的 Java 源代
码。
这本书将对运行时间的数学分析与所分析算法的 Java 源代码结合在一
起。这意味着一些方程中包含了源代码中也出现的变量。这些变量的排版
保持一致，无论是在源代码中还是在方程中。最常见的此类变量是 n 变量
，它始终毫无例外地指代当前存储在数据结构中的项目数量。
