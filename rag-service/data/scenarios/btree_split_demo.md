# B树分裂演示序列

## 演示步骤（阶数 m=3）

### Frame 1：初始状态
- 空树

### Frame 2：插入 10
- 创建根节点，插入 10
- 节点：[10]

### Frame 3：插入 20
- 根节点未满（<2个关键字）
- 直接插入，保持有序
- 节点：[10, 20]

### Frame 4：插入 30
- 根节点已满（2个关键字）
- 需要执行分裂

### Frame 5：分裂过程
- 取中间关键字 20
- 左侧关键字 [10] 留在原节点
- 右侧关键字 [30] 形成新节点
- 中间关键字 20 上升为新根

### Frame 6：分裂完成
- 新树结构：
  ```
      [20]
     /    \
  [10]   [30]
  ```
- 根节点：[20]
- 左子节点：[10]
- 右子节点：[30]

### Frame 7：插入 40
- 插入到右子节点 [30]
- 节点未满，直接插入
- 右子节点：[30, 40]

### Frame 8：插入 50
- 右子节点 [30, 40] 已满
- 需要执行分裂

### Frame 9：分裂右子节点
- 取中间关键字 40
- 左侧关键字 [30] 留在原节点
- 右侧关键字 [50] 形成新节点
- 中间关键字 40 上升到父节点

### Frame 10：父节点检查
- 父节点 [20] 插入 40 后变为 [20, 40]
- 父节点未满，无需继续分裂

### Frame 11：分裂完成
- 新树结构：
  ```
        [20, 40]
       /   |    \
    [10] [30]  [50]
  ```
- 根节点：[20, 40]
- 子节点：[10], [30], [50]

## 关键帧解释

- **Frame 2-3**：正常插入，无需分裂
- **Frame 4-6**：根节点分裂，创建新根
- **Frame 7**：正常插入到子节点
- **Frame 8-11**：子节点分裂，关键字上升到父节点

## 知识点总结

1. B树节点最多 m-1 个关键字（m=3时最多2个）
2. 插入满节点时触发分裂
3. 分裂时取中间关键字上升到父节点
4. 根节点分裂会增加树的高度
5. B树保证所有叶子节点在同一层
