# 最小生成树：Kruskal 与 Prim 算法对比

## 什么是最小生成树（MST）

给定一个带权无向连通图 G=(V, E)，最小生成树（Minimum Spanning Tree）是包含所有顶点、边权总和最小的生成树（V-1 条边、无环、连通）。MST 不唯一（多条边权相同时），但最小权值和唯一。

## Kruskal 算法

思路：全局贪心，按边权从小到大排序，依次考虑每条边——若加入后不形成环则选入，否则跳过。用并查集（UFDS）判断两端点是否已连通。

步骤：
1. 将所有边按权值升序排序
2. 初始化并查集，每个顶点自成集合
3. 遍历排序后的边：若 find(u) != find(v)，选入该边并 union(u, v)
4. 选够 V-1 条边即停止

时间复杂度：O(E log E)（排序主导），并查集操作近似 O(1)。
空间复杂度：O(E + V)。
数据结构依赖：边列表 + 并查集。

## Prim 算法

思路：局部贪心，从任意顶点出发，维护一个"已选顶点集合 S"，每次取连接 S 与 V\S 的最小权边，将新顶点加入 S。

步骤：
1. 任选一个起始顶点加入 S
2. 将与 S 相邻的所有边加入优先队列（最小堆）
3. 每次从优先队列取出权最小的边 (u, v)：若 v 已在 S 中则跳过，否则选入并将 v 加入 S
4. 重复直到 S 包含所有顶点

时间复杂度：
- 二叉堆 + 邻接表：O((V+E) log V)
- Fibonacci 堆：O(E + V log V)
- 数组扫描（无堆）：O(V²)，适合稠密图

空间复杂度：O(V + E)。
数据结构依赖：优先队列（最小堆）+ 邻接表。

## 选型对比

| 维度 | Kruskal | Prim |
|------|---------|------|
| 贪心策略 | 全局选最小边 | 局部扩展最小边 |
| 时间复杂度 | O(E log E) | O((V+E) log V) 或 O(V²) |
| 适合图类型 | 稀疏图（E ≈ V） | 稠密图（E ≈ V²） |
| 核心数据结构 | 并查集 | 优先队列 |
| 是否需要邻接表 | 不需要（只需边列表） | 需要 |
| 图不连通时 | 自然得到最小生成森林 | 只能得到一棵树的 MST |

工程建议：默认用 Kruskal（实现简单、不依赖邻接表、稀疏图快）；图很稠密（E 接近 V²）或需要在线处理（边逐步加入）时用 Prim。

## 面试要点

- 两者都是贪心，正确性靠切割性质（Cut Property）：任意切割中权最小的横跨边必属于某棵 MST
- Kruskal 的瓶颈在排序，Prim 的瓶颈在优先队列操作
- 稠密图 Prim O(V²) 优于 Kruskal O(V² log V)；稀疏图 Kruskal O(E log E) 优于 Prim O(E log V)
- 并查集在 Kruskal 中的作用：O(α(n)) 判断加边是否成环，比 DFS 判环快得多
- 变体：次小生成树（枚举替换边）、瓶颈生成树（最小化最大边权）
