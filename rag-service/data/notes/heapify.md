# 堆化操作详解

## 核心原理

堆是一种完全二叉树，分为最大堆和最小堆：
- **最大堆**：每个父节点的值 >= 子节点的值
- **最小堆**：每个父节点的值 <= 子节点的值

堆通常用数组表示，父子关系：
- 父节点：i → 子节点：2i+1, 2i+2
- 子节点：i → 父节点：(i-1)/2

## 向上堆化（Heapify Up）

### 应用场景

插入新元素后，需要向上调整以恢复堆性质。

### 步骤

1. 将新元素插入数组末尾
2. 与父节点比较：
   - 最小堆：如果小于父节点，交换位置
   - 最大堆：如果大于父节点，交换位置
3. 重复步骤2，直到到达根节点或满足堆性质

### 示例（最小堆）

```
插入元素3到堆[5, 6, 8, 9]

步骤1：插入到末尾 → [5, 6, 8, 9, 3]
步骤2：比较3和父节点9（索引3）→ 3<9，交换
       → [5, 6, 8, 3, 9]
步骤3：比较3和父节点6（索引1）→ 3<6，交换
       → [5, 3, 8, 6, 9]
步骤4：比较3和父节点5（索引0）→ 3<5，交换
       → [3, 5, 8, 6, 9]
步骤5：到达根节点，结束
```

### 伪代码

```
function heapifyUp(heap, index):
    while index > 0:
        parent = (index - 1) // 2
        if heap[index] < heap[parent]:  # 最小堆
            swap(heap[index], heap[parent])
            index = parent
        else:
            break
```

## 向下堆化（Heapify Down）

### 应用场景

删除根节点后，需要向下调整以恢复堆性质。

### 步骤

1. 将最后一个元素移到根节点位置
2. 与子节点比较：
   - 最小堆：找到最小子节点，如果大于最小子节点，交换位置
   - 最大堆：找到最大子节点，如果小于最大子节点，交换位置
3. 重复步骤2，直到到达叶子节点或满足堆性质

### 示例（最小堆）

```
删除堆[3, 5, 8, 6, 9]的根节点3

步骤1：最后一个元素9移到根 → [9, 5, 8, 6]
步骤2：比较9与子节点5和8 → 最小子节点5
       9>5，交换 → [5, 9, 8, 6]
步骤3：比较9与子节点6（右子节点）→ 9>6，交换
       → [5, 6, 8, 9]
步骤4：到达叶子节点，结束
```

### 伪代码

```
function heapifyDown(heap, index, size):
    while True:
        left = 2 * index + 1
        right = 2 * index + 2
        smallest = index
        
        if left < size and heap[left] < heap[smallest]:
            smallest = left
        if right < size and heap[right] < heap[smallest]:
            smallest = right
            
        if smallest != index:
            swap(heap[index], heap[smallest])
            index = smallest
        else:
            break
```

## 建堆（Build Heap）

### 应用场景

将普通数组转换为堆。

### 步骤

从最后一个非叶子节点开始，依次向下堆化：

```
数组：[9, 6, 8, 5, 3]

最后一个非叶子节点索引：1（值为6）

步骤1：堆化索引1 → [9, 3, 8, 5, 6]
步骤2：堆化索引0 → [3, 5, 8, 9, 6]
```

### 伪代码

```
function buildHeap(heap):
    size = len(heap)
    for i in range((size // 2) - 1, -1, -1):
        heapifyDown(heap, i, size)
```

### 时间复杂度

建堆的时间复杂度为O(n)，而非O(n log n)：
- 底层节点无需调整
- 顶层节点调整次数多但数量少

## 堆排序

### 原理

1. 建堆（最大堆）
2. 反复提取根节点（最大值），放在数组末尾
3. 对剩余元素向下堆化

### 示例

```
数组：[5, 3, 8, 6, 9]

步骤1：建最大堆 → [9, 6, 8, 3, 5]
步骤2：提取9，放在末尾 → [5, 6, 8, 3, 9]
       向下堆化 → [8, 6, 5, 3, 9]
步骤3：提取8，放在倒数第二 → [3, 6, 5, 8, 9]
       向下堆化 → [6, 3, 5, 8, 9]
步骤4：提取6 → [5, 3, 6, 8, 9]
步骤5：提取5 → [3, 5, 6, 8, 9]
步骤6：提取3 → [3, 5, 6, 8, 9]

最终排序结果：[3, 5, 6, 8, 9]
```

## 时间复杂度

| 操作 | 时间复杂度 |
|------|-----------|
| 向上堆化 | O(log n) |
| 向下堆化 | O(log n) |
| 建堆 | O(n) |
| 堆排序 | O(n log n) |

## 关键要点

- 向上堆化用于插入操作
- 向下堆化用于删除操作
- 建堆从最后一个非叶子节点开始
- 堆排序是不稳定排序
