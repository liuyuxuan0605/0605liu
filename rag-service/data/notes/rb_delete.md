# 红黑树删除操作详解

## 核心原理

红黑树删除操作分为两个阶段：
1. BST删除阶段：按BST规则删除节点
2. 修复阶段：恢复红黑树的5条性质

## 红黑树性质回顾

1. 每个节点非红即黑
2. 根节点为黑
3. 所有叶子（NIL）为黑
4. 红节点的子节点必为黑（无连续红）
5. 任意节点到叶子的路径黑节点数相同（黑高一致）

## 删除阶段

与BST删除相同，分三种情况：
1. 叶子节点 → 直接删除
2. 一个子节点 → 子节点上位
3. 两个子节点 → 后继替换后删除

## 修复阶段

只有删除**黑色节点**时才需要修复（删除红色节点不破坏任何性质）。

### 核心问题

删除黑色节点后，该路径的黑高减少1，导致性质5被破坏。

### 双黑节点概念

将替代节点标记为"双黑"（计为2个黑节点），然后通过调整消除双黑。

## 删除修复的四种情况

设x为双黑节点，w为x的兄弟节点：

### 情况1：w为红色

**处理**：
1. w变黑，x的父节点p变红
2. 对p旋转（x在左则左旋，x在右则右旋）
3. w更新为旋转后的新兄弟

**目的**：将情况转化为w为黑色的情况。

### 情况2：w为黑，且w的两个子节点都为黑

**处理**：
1. w变红
2. x的双黑属性传递给父节点p
3. p成为新的x，继续向上调整

**目的**：将双黑向上传递。

### 情况3：w为黑，w的远侄子为红

**处理**：
1. 对p旋转（x在左则左旋，x在右则右旋）
2. w继承p的颜色
3. p和w的近侄子变黑

**目的**：消除双黑，调整结束。

### 情况4：w为黑，w的近侄子为红，远侄子为黑

**处理**：
1. 对w旋转（x在左则右旋，x在右则左旋）
2. w变红，近侄子变黑
3. 转化为情况3

**目的**：转化为情况3。

## 左右对称处理

以上四种情况针对x在父节点左侧，右侧情况对称处理。

## 示例

删除序列演示：
```
初始红黑树：
        10(B)
       /    \
    5(R)    15(B)
   /  \     /  \
 3(B) 7(B) 12(B)20(B)

删除3（黑色叶子）：
- x=5的左子（NIL，双黑）
- w=7（黑色，两子均黑）
- 情况2：7变红，x=5（双黑）
- w=15（黑色，两子均黑）
- 情况2：15变红，x=10（双黑）
- x为根，直接变黑
- 最终根10变黑，7和15变红

结果：
        10(B)
       /    \
    5(B)    15(R)
   /  \     /  \
 NIL 7(R) 12(B)20(B)
```

## 删除与插入的对比

| 特性 | 插入 | 删除 |
|------|------|------|
| 修复复杂度 | 简单（最多2次旋转） | 复杂（最多3次旋转） |
| 修复次数 | 单次 | 可能多次向上传递 |
| 颜色改变 | 较少 | 较多 |

## 时间复杂度

- **删除操作**：O(log n)
- **修复操作**：O(log n)
- **总体**：O(log n)

## 关键要点

- 删除红色节点无需修复
- 删除黑色节点才需要修复
- 双黑节点的概念是理解删除修复的关键
- 四种情况涵盖所有可能，最终都能消除双黑
