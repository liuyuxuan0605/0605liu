# BST 插入操作详解

## 核心原理

二叉搜索树（BST）的插入操作必须保持其核心特性：
- 左子树所有节点值 < 当前节点值
- 右子树所有节点值 > 当前节点值
- 左右子树均为二叉搜索树

## 插入步骤

1. **若树为空**：直接将新节点作为根节点

2. **若树非空**：从根节点开始递归比较
   - 新值 < 当前节点值 → 递归插入左子树
   - 新值 > 当前节点值 → 递归插入右子树
   - 新值 = 当前节点值 → 通常不插入（BST不允许重复值）

3. **找到空位**：当递归到空节点时，创建新节点并返回

## 示例

插入序列 [5, 3, 7, 1, 4, 6, 8] 的过程：

```
插入5 → 根节点
插入3 → 5的左子树
插入7 → 5的右子树
插入1 → 3的左子树
插入4 → 3的右子树
插入6 → 7的左子树
插入8 → 7的右子树
```

最终树结构：
```
    5
   / \
  3   7
 / \ / \
1  4 6  8
```

## 时间复杂度

- **平均情况**：O(log n) — 树接近完全平衡
- **最坏情况**：O(n) — 树退化为单链表（有序插入时）

## 关键要点

- 插入操作始终从根节点开始，沿比较路径向下
- 新节点始终作为叶子节点插入
- 插入有序数据会导致树退化成链表，这是AVL树和红黑树诞生的原因
