# AVL 删除操作详解

## 核心原理

AVL树的删除操作与BST类似，但删除后可能破坏平衡，需要通过旋转恢复平衡。与插入不同，删除可能触发多次旋转（从删除点一直到根）。

## 删除步骤

### 第一步：BST删除

按照BST的三种情况删除目标节点：
1. 叶子节点 → 直接删除
2. 一个子节点 → 子节点上位
3. 两个子节点 → 后继/前驱替换后删除

### 第二步：向上回溯

从删除点开始，沿parent链向上回溯，更新每个节点的height和balance factor。

### 第三步：检测不平衡

检查每个节点的balance factor（bf = 左子树高度 - 右子树高度）：
- bf ∈ {-1, 0, 1} → 平衡，继续向上
- |bf| > 1 → 失衡，执行旋转

### 第四步：旋转修复

与插入相同，四种旋转情况：

| 情况 | 条件 | 操作 |
|------|------|------|
| LL | bf=+2, left.bf=+1 | rotateRight |
| LR | bf=+2, left.bf=-1 | rotateLeft(left), rotateRight |
| RR | bf=-2, right.bf=-1 | rotateLeft |
| RL | bf=-2, right.bf=+1 | rotateRight(right), rotateLeft |

### 第五步：继续向上

与插入不同！删除后旋转可能不会完全恢复高度，需要继续向上检查，直到根节点或不再失衡。

## 删除与插入的关键区别

| 特性 | 插入 | 删除 |
|------|------|------|
| 旋转次数 | 最多1次旋转 | 可能多次旋转（O(log n)次） |
| 停止条件 | 旋转后高度恢复，停止 | 必须检查到根节点 |
| 复杂度 | O(log n) | O(log n) |

## 示例：多次旋转

删除序列演示：
```
初始AVL树：
        15
       /  \
      6    20
     / \   / \
    4   8 18  25
   /
  1

删除1（叶子节点）：
- 更新height(4) = 0
- bf(6) = +1 → 平衡
- bf(15) = -1 → 平衡
- 无需旋转

删除25（叶子节点）：
- bf(20) = 0 → 平衡
- bf(15) = +1 → 平衡
- 无需旋转

删除18（叶子节点）：
- bf(20) = -1 → 平衡
- bf(15) = +2 → 失衡！
  - bf(6) = +1 → LL情况
  - rotateRight(15)

旋转后：
        6
       / \
      4   15
     /   /  \
    1   8    20
```

## 删除导致高度降低的情况

删除后节点高度可能降低，影响祖先的平衡因子：

**场景A：删除前bf=0，删除后bf=±1**
- 高度不变，无需继续向上

**场景B：删除前bf=±1，删除后bf=0**
- 高度降低1，需要继续向上检查祖先

**场景C：删除前bf=±1，删除后bf=±2**
- 失衡！执行旋转

## 时间复杂度

- **删除操作**：O(log n)
- **平衡调整**：O(log n)（最多O(log n)次旋转）
- **总体**：O(log n)

## 关键要点

- 删除是AVL树中最复杂的操作
- 必须沿parent链检查到根节点
- 旋转后仍需检查祖先的平衡状态
- 最坏情况需要O(log n)次旋转
