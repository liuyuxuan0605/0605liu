# 双向链表（Doubly Linked List）删除节点要改哪些指针

双向链表每个节点同时持有 `prev`（前驱）和 `next`（后继）两个指针，
因此可从任意节点 O(1) 找到前驱，删除/插入比单链表灵活，但**维护的指针更多**。

## 删除节点 x（已知 x 本身）
要断开 x，需把它前后两个节点重新连起来，共改 **4 个指针**（两条边各两个方向）：
1. `x->prev->next = x->next`   // x 的前驱改指向 x 的后继
2. `x->next->prev = x->prev`   // x 的后继改指向 x 的前驱
（随后 `delete x` 释放）
两条边都要改，否则链表断裂；顺序无所谓，但必须先读取 `x->prev`/`x->next` 再断开。

## 在节点 p 后插入新节点 x
同样改 4 个指针：
1. `x->prev = p`
2. `x->next = p->next`
3. `p->next->prev = x`        // 原后继的前驱指向 x
4. `p->next = x`              // p 的后继指向 x
建议先设 x 的双向，再改邻居指向 x，最后改 p->next，避免悬空。

## 与单链表的区别
- 单链表删节点必须知道**前驱**，双向链表知道节点本身即可
- 代价：每个节点多一个指针（多约 1 倍指针内存），插入删除多维护一条反向边

## 典型应用
LRU 缓存（O(1) 把任意节点移到表头）、浏览器的前进/后退（配合栈/双向链表）
