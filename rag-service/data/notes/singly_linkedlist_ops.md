# 单链表（Singly Linked List）的插入与删除

单链表每个节点只持有指向下一个节点的 `next` 指针，最后一个节点 `next == null`。
插入删除的本质是**改写指针指向**，而不是移动数据。

## 在节点 p 后面插入新节点 x
这是单链表最高频的操作（单链表没有 `prev`，无法 O(1) 找前驱）：
1. `x->next = p->next`   // 先让新节点指向 p 的后继
2. `p->next = x`         // 再让 p 指向新节点
**顺序不能反**：若先 `p->next = x` 会丢失原后继链表。已知 p 时复杂度 O(1)。

## 删除节点 p 的后继（或删除指定值的节点）
- 删除 p 的后继：`p->next = p->next->next`（跳过中间节点）
- 删除值为 v 的节点：先遍历找到前驱 p（`p->next->val == v`），再执行上式
删除已知前驱是 O(1)；按值删除需先查找 O(n)。

## 头插 / 尾插
- 头插：`x->next = head; head = x`，O(1)，结果逆序
- 尾插：维护 `tail` 指针时 `tail->next = x; tail = x`，O(1)

## 坑点
- 插入必须"先连后断"，否则链表断裂
- 删除节点后若用 C/C++ 需手动 `delete` 防内存泄漏
- 边界：空表、删头节点要单独处理 `head` 指针
