# 循环队列（Circular Queue）怎么判断是满还是空

循环队列是普通队列的数组实现优化：用**取模**让尾指针在到达数组末端后绕回头部，
避免"假溢出"（数组前面空着却因 rear 到顶而报满）。关键难点是**区分满和空**。

## 为什么不能简单用 `front == rear`
若用 `front == rear` 表示空，那"满"时也恰好 `front == rear`（绕一圈回来），两者无法区分。
常见三种解法：

### 解法 1：牺牲一个存储单元（最常用）
约定数组最多存 `cap-1` 个元素：
- 空：`front == rear`
- 满：`(rear + 1) % cap == front`
入队：`rear = (rear + 1) % cap`；出队：`front = (front + 1) % cap`

### 解法 2：维护 size 计数器
额外记录 `size`：
- 空：`size == 0`
- 满：`size == cap`
无需牺牲单元，逻辑最清晰，常与 `front/rear` 配合。

### 解法 3：布尔标志位
加一个 `full` 标志：
- 入队后置 `full = true`，出队后置 `false`
- 空：`!full && front==rear`；满：`full`

## 下标环绕
所有移动用取模：`next = (idx + 1) % cap`，使逻辑上数组首尾相连成环。

## 与普通队列 / 阻塞队列的关系
- 循环队列解决"数组队列的假溢出"，是**固定容量**队列的高效实现
- 阻塞队列通常在循环队列基础上加锁与条件变量，实现多线程的等待/唤醒
