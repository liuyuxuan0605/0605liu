# 线段树与树状数组对比

## 线段树（Segment Tree）原理

线段树是一棵二叉树，每个节点对应数组的一个区间 [l, r]。根节点覆盖整个数组 [0, n-1]，叶子节点覆盖单个元素。用于在 O(log n) 时间内完成区间查询（求和/最值）和区间/单点更新。

核心操作：
- 建树（Build）：递归地将区间二分，O(n) 时间
- 单点更新（Point Update）：从叶子沿路径向上更新所有祖先的聚合值，O(log n)
- 区间查询（Range Query）：递归地拆分查询区间，合并覆盖到的节点值，O(log n)
- 区间更新（Range Update）：配合懒惰传播（Lazy Propagation），O(log n)

存储方式：通常用数组模拟完全二叉树，节点 i 的左孩子为 2i+1，右孩子为 2i+2。数组大小开 4n 即可。

## 树状数组（Fenwick Tree / BIT）原理

树状数组利用二进制 lowbit 性质，用一维数组 tree[1..n] 维护前缀和。每个位置 i 管辖长度为 lowbit(i) 的区间。

核心操作：
- 单点更新：从 i 开始，每次加 lowbit(i) 向上跳，O(log n)
- 前缀查询：从 i 开始，每次减 lowbit(i) 向下跳，O(log n)
- 区间查询 [l, r]：prefix(r) - prefix(l-1)

lowbit(i) = i & (-i)，即 i 的二进制最低位的 1 所代表的值。

## 线段树 vs 树状数组

| 维度 | 线段树 | 树状数组 |
|------|--------|----------|
| 区间查询 | 支持（求和/最值/任意聚合） | 仅支持可逆运算（如求和），不支持区间最值 |
| 区间更新 | 支持（懒惰传播） | 需要差分技巧，且仅限求和类 |
| 单点更新 | O(log n) | O(log n) |
| 代码量 | 较多（递归/迭代 + lazy） | 极少（两个循环） |
| 空间 | 4n | n |
| 常数 | 较大（递归开销） | 极小（位运算） |
| 适用场景 | 通用：区间最值、区间更新、复杂操作 | 轻量：前缀和、逆序对、离线统计 |

面试选型：如果只需要前缀和/单点更新，优先树状数组（代码短、常数小）；如果需要区间最值（RMQ）或区间更新（lazy），必须线段树。

## 面试高频问题

- 线段树怎么做区间查询：递归拆分，若当前节点区间完全被查询区间包含则直接返回值，否则递归左右孩子再合并
- 单点更新怎么传播：修改叶子值后，沿路径向上重新计算每个祖先的聚合值（sum = left.sum + right.sum）
- 懒惰传播（Lazy Propagation）：区间更新时不立即下推到叶子，在节点上打标记；查询时按需下推，保证 O(log n)
- 树状数组为什么不能做区间最值：最值不满足可逆性（知道 [1,r] 和 [1,l-1] 的最值推不出 [l,r] 的最值）
- 树状数组求逆序对：离散化后从右往左插入，query(i-1) 得到已插入中小于当前值的个数
